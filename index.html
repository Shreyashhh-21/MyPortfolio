PROJECT 01 / Android Application | Personal Device Security

SecurityX

SecurityX is an Android-based personal device recovery and anti-theft application engineered to help users recover and locate their devices through predefined SMS-based commands, functioning even when mobile data or internet access is unavailable.

Key Engineering Highlights:

  • SMS-Based Device Recovery: Predefined encrypted command triggers that activate without an internet connection.
  • Location Retrieval: High-precision GPS coordinates acquired via Android Location Services and sent via return SMS.
  • Emergency Device Alert: Triggers audible alarm and siren functionality even if device is set to silent.
  • SIM Monitoring & Offline Approach: Detects unauthorized SIM changes and executes defensive protocols locally.
  • Permission-Based Security: Strict adherence to Android security models and permission boundaries.
